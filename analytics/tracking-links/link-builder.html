DSP Link Tagger

Adds a hidden tag to a link so Google Analytics can show where the traffic came from — which email or post drove someone to the site.

  1. Paste the link you're going to share. For one of our own pages you can paste just the path — /get-involved/ — and it fills in the rest.
  2. Pick where it's going out (email, Instagram, …).
  3. Name the campaign — what this send is about, e.g. june-2026. Use the same name on every link in one email.
  4. Copy the tagged link and paste it where your link would normally go in Mailchimp or the social post. Done — nothing to save here.
Naming rules (the tool enforces these)

Everything is forced to lowercase with hyphens, no spaces or punctuation, because Google Analytics treats June 2026, june-2026, and June-2026 as three different campaigns. Use the same campaign name for every link in one send so they group together.
