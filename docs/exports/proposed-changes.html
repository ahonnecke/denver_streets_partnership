Proposed Website Changes

denverstreetspartnership.org  ·  June 2026  ·  from Ashton
Nothing here has been changed yet. This is a plain-language list of what we'd recommend fixing, what each change does, and why. Reply with the numbers you're comfortable with and we'll do those — one at a time, carefully, all reversible.

A. Website changes — these need your OK

Done safely: full backup first, one at a time, checked on phone and computer, every change reversible.

1. Let people zoom on their phones
The site currently blocks pinch-to-zoom on phones. About a third of our visitors are on mobile, and blocking zoom is an accessibility problem (and against accessibility guidelines). This lets everyone zoom in.
2. One "Donate" link instead of two we'll test this carefully
Right now two different web addresses both lead to Donate, so the numbers get split and we can't see how donations are really doing. We'd settle on one clean donate page. Makes donations countable and the button easy to share in emails. Because it's the donation path, we back it up and test it thoroughly.
3. Fix the broken volunteer link
The current volunteer link goes to a dead end — it only works inside an email, not on the website. We'd point it at a real signup page so people who want to help actually can.
4. Remove a dead tracking tag
An old analytics tag still loads on every page but stopped collecting data back in 2024. Removing it makes pages a touch lighter, with no downside.
5. Update the footer year
The footer says "© 2020," which makes the site look abandoned to a first-time visitor or funder. We'd set it to update to the current year automatically.
6. Tighten a couple of security basics
Hide staff usernames from public view and switch off an unused back-door feature. Not urgent — the web host already blocks break-in attempts — just good housekeeping.

B. Measurement improvements — we handle these, no action needed from you

No risk to the website; this is about finally being able to see what's working.

7. Tag our newsletter & social links
We add a small invisible tag to the links we share in emails and social posts so Analytics can show which email or post drove people to the site. Today, over half our traffic shows up as "direct / unknown" because links aren't tagged — so we can't tell what's working.
8. Turn on goal tracking
Tell Analytics to count donations and form sign-ups as goals. Right now it counts zero — we can see visits, but not whether anyone donated or signed up. The information is already being collected; it just needs switching on.

C. Bigger opportunity — worth a conversation

9. Do more of what's already working
Our single best page is the Colorado BRT comment guide — people spend about a minute on it, far more than anywhere else. It's worth building more pages in that "here's exactly how to take action" format, and putting recent articles on the homepage (which today leads with program tiles, not the latest news). This is a content decision for the team, not a quick technical fix.
What we need from you: tell us which of 1–6 you're OK with (B and C don't need approval — we'll handle 7–8, and 9 we can talk through whenever). We'll start with whatever you approve, carefully and reversibly.
